
# README
## Summary
This project aims to modernize and simplify the use and show design for the light up glasses in the University of Idaho Marching Band. This project utilizes code from Dr. Rinker and Benjamin Jeffery. The modernization is being done by Jake Gendreau, Derek McNee, Paul Shannon, and Darwin Porth.

## Parts of the Project
This project consists of three parts.
1) The [broadcast software](./Documents/Documentation/Broadcast/broadcast.md).
    * This is the software which is run during shows

2) The [receiver software](./Documents/Documentation/Glasses/glasses.md)
    * This is the software which runs on the glasses themselves

3) The [show design software](./Documents/Documentation/ShowDesign/showdesign.md)
    * This is the software which is used to design the lighting patterns for shows
